# 사이트 설계도(PRD) — (미정: 사이트 이름)

작성일: 2026-11-15 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
소규모 건설회사 임직원과 건설 초보자를 위해 견적·인허가·준공·입찰·안전 서류 업무를 대신 해 주는 곳.

## 2. 손님
- 누가:
  - 서류 담당자가 따로 없는 소규모 건설사 대표
  - 서류 업무를 맡았지만 경험이 적은 건설사 사무 직원
  - 건설업 면허를 막 땄거나 새로 시작한 건설 초보 창업자
- 어디서 알고 오나: 구글 검색, 네이버 검색·블로그

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 비용 — 서류별 대행 비용이 얼마인지
2. 처리 기간 — 맡기면 며칠 안에 나오는지
3. 준비할 자료 — 무엇을 보내면 되는지 (도면, 물량표, 사진 등)
4. 누가 해 주나 — 건설 실무를 아는 사람이 하는지, 믿어도 되는지

## 4. 믿게 할 증거 (실제로 있는 것만)
- 건설 실무 경력 (연수·분야: 미정)
- 관련 자격증 (자격증 이름: 미정)
- 작업 샘플 (개인정보를 가린 실제 작업 서류 예시)
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 무료 견적 받기
- 누르면: 문의 폼

## 6. 페이지 구성 (위에서 아래로)
1. 첫 화면 — 한 문장 + [무료 견적 받기] 버튼
2. 대행 서류 — 견적서·내역서 / 인허가·신고 서류 / 준공·기성 서류 / 입찰·면허 서류 / 위험성평가 / 공사사진대지 / 일부 업무 자동화
3. 맡기는 방법 — 견적 요청 → 준비할 자료 안내 → 작업 → 전달 (비용·처리 기간은 "견적 후 안내")
4. 누가 해 주나 — 건설 실무 경력, 관련 자격증, 작업 샘플
5. 후기 자리 (비워 둠)
6. 문의 폼 (무료 견적 받기)

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 필요한 서류 종류 (견적서·내역서 / 인허가·신고 / 준공·기성 / 입찰·면허 / 위험성평가 / 공사사진대지 / 업무 자동화 / 기타 중 고르기)
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 사이트·회사 이름: (미정)
- 가격: (미정 — 확정 전까지 "견적 후 안내")
- 처리 기간: (미정)
- 위치: (미정)
- 연락 방법: (미정)
- 경력 연수·자격증 이름: (미정)

## 9. 이번에 넣지 않을 것
- 결제
- 회원가입·로그인
- 도면·사진 파일 올리기 (자료는 견적 후 따로 받기)
- 알림 메일
- 서류별 가격표 (가격이 정해지면 추가)

## 10. 첫 화면 한 문장 후보
1. 현장은 소장님이, 서류는 저희가 맡겠습니다.
2. 견적서부터 준공 서류까지, 건설 실무를 아는 사람이 대신 작성합니다.
3. 처음 하는 건설 서류도 무엇을 준비할지부터 알려 드립니다.

## 11. 다음에 할 것
- 사이트·회사 이름, 연락 방법, 경력 연수, 자격증 이름 채우기
- 서류별 비용과 처리 기간이 정해지면 가격표 넣기
- 실제 후기가 생기면 후기 자리 채우기
- 작업 샘플 이미지 준비 (개인정보 가리기)
- 도면·사진 파일 올리기 기능 검토

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 고급스러운 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
